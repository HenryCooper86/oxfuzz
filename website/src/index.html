oxfuzz is an open-source desktop app for fuzzing C, C++ and Rust code. It finds functions worth fuzzing, drafts a harness for you to review, runs the fuzzer in a sandbox, and turns every crash into a finding you can reproduce.

Download v{{VERSION}} View the source on GitHub

Free under the MIT license. Runs on macOS, Linux and Windows.

From a codebase to a triaged crash in four steps

  1. Discover

    oxfuzz scans your project and ranks the functions most worth fuzzing, with a short reason for each.

  2. Review the harness

    A model drafts the harness. It is compiled and smoke-tested in the sandbox, then waits for your approval.

  3. Run

    Start a time-limited campaign and watch coverage and speed live. Stop it whenever you like; the results stay.

  4. Triage

    Crashes are replayed, grouped by stack, and rated. Export a report, SARIF, or an issue draft.

Four engines, one workflow

oxfuzz drives the fuzzers you already trust. You choose the engine; the steps around it stay the same.

libFuzzer

In-process and fast. The usual first choice for a library.

syzkaller

syzkaller setup guide

The fuzzer runs untrusted code. You stay in charge of it.

Sandboxed

Every build and every run happens in a Docker container with no network. Nothing generated runs on your machine directly.

Approved by a person

A harness is reviewed by a model and then by you. Campaigns only run harnesses you approved.

Your choice of model

Use OpenAI, Anthropic, Gemini, Azure OpenAI, Ollama, or any OpenAI-compatible endpoint, with spending limits you set.

Also included: scheduled campaigns, corpus tools, project search, reusable skills and agents, and DefectDojo, GitHub and GitLab hand-off.

oxfuzz is open source, and you can help shape it

The whole project is on GitHub under the MIT license: the desktop app, the service behind it, and the sandbox. Read it, run it, change it.

Any improvement is welcome. A bug report, a fixed typo, a new example target, or a feature you built for your own team all make oxfuzz better for the next person.

Download oxfuzz {{VERSION}}

Pick the package for your system. You also need Docker, and the sandbox kit to build the fuzzing environment.

This is an early release. macOS packages are ad-hoc signed and not notarized, and Windows packages are unsigned, so your system may warn you before installing. Only the macOS Apple silicon package is tested live for each release; the others are built and checked in CI.

Set up in three steps

  1. Install the app. On macOS, drag oxfuzz to Applications. On Linux, install the DEB or RPM, or make the AppImage executable. On Windows, run the installer.
  2. Build the sandbox. Extract the sandbox kit and run the script below. It needs Bash, Python 3 and Docker (on Windows, a WSL 2 shell), and a few GB of disk space. 
    tar -xzf oxfuzz-sandbox-kit-{{VERSION}}.tar.gz
cd oxfuzz-sandbox-kit-{{VERSION}}
./scripts/build-sandbox.sh
  3. Add a model provider and open a project. Enter your provider in Settings, then open a source folder and follow the workflow.

Kernel fuzzing with syzkaller also needs an instrumented kernel, a root filesystem and a guest SSH key, which the download does not include.

Verify your download

Compare the SHA-256 of the file with the published checksums before you install it. 

# macOS
shasum -a 256 your-download.dmg
# Linux
sha256sum your-download.AppImage
# Windows PowerShell
Get-FileHash .\your-download.msi -Algorithm SHA256
