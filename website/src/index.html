BEFORE YOUR FIRST CAMPAIGN

Desktop app.
Isolated engines.

Install Docker and keep its daemon running. The sandbox kit builds the pinned engine toolchain locally; it does not include the application source.

1

Install the desktop app

Open the package for your system. On macOS, move oxfuzz to Applications. On Linux, install the DEB/RPM or make the AppImage executable. On Windows, run the installer.

2

Build the sandbox

Download and extract the sandbox kit. Run these commands from its directory using Bash, Python 3 and Docker. Windows users need a WSL 2 shell with Docker integration. The first build downloads toolchains and needs several GB of disk space. 

tar -xzf oxfuzz-sandbox-kit-{{VERSION}}.tar.gz
cd oxfuzz-sandbox-kit-{{VERSION}}
./scripts/build-sandbox.sh

Keep the resulting image tag oxfuzz/fuzz-sandbox:0.2.2. The desktop app uses this local image.

3

Connect a provider and open a project

Configure your chosen AI provider in Settings. Provider access is required for AI assistance and normal harness review. Confirm sandbox readiness, discover a target, and review the harness before approving execution.

Kernel fuzzing with syzkaller also needs a compatible instrumented kernel, root filesystem and guest SSH key. These are not included in the desktop download. Physical automotive testing requires separate setup and approval.

VERIFY YOUR DOWNLOAD

Check the bytes.

Compare the SHA-256 of your download with the published checksums before installing. 

# macOS
shasum -a 256 your-download.dmg
# Linux
sha256sum your-download.AppImage
# Windows PowerShell
Get-FileHash .\your-download.msi -Algorithm SHA256

Checksums detect incomplete or altered files. They are not a substitute for a trusted publisher signature.
